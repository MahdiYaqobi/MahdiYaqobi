# Hi, I'm Mahdi 👋

I clean and analyze messy data with Python and pandas, so you can
trust your numbers and make decisions based on them.

## What I can help with

- **Data cleaning:** duplicates, missing values, inconsistent formats,
  invalid entries, and non-product records
- **Exploratory analysis:** trends, customer and product breakdowns,
  and a short summary of what matters
- **Basic predictive modeling:** a classification baseline, such as
  customer churn, tuned for a business goal

## Featured projects

**[Online Retail: From Messy Transactions to Business Insights](https://github.com/MahdiYaqobi/online-retail-data-cleaning)**
Cleaned 541,909 transaction lines from a UK online retailer, audited the
result, and answered seven business questions. The audit caught three bulk
orders (£284,623, 2.8% of revenue) that were cancelled within minutes. Left
in, they would have doubled the apparent cancellation rate (4.6% instead of 2.3%).

**[Nashville Housing: Data Cleaning](https://github.com/MahdiYaqobi/nashville-housing-cleaning)**
A client-style project on 56,477 home sales. Written plan, full change log,
and a report a non-programmer can read. Removed 104 duplicate sales, filled 29
missing addresses, flagged unusual values, and left alone what only the
client can explain. All 12 final quality checks pass.

**[Telco Customer Churn Prediction](https://github.com/MahdiYaqobi/customer-retention-analytics)**
Logistic Regression on 7,043 customers, with a business-focused threshold
(0.30) chosen on training data only, not the test set. Recall 0.751,
ROC-AUC 0.842. Includes a reusable script for scoring new customers.

**[Customer Data Cleaning and Quality Analysis](https://github.com/MahdiYaqobi/customer-data-cleaning)**
Cleaned a messy customer dataset (1,007 rows): removed duplicates, standardized
formats, and flagged invalid ages and emails. Missing financial values were
not invented, and a data quality report lists every open issue.

## How I work

- **Check before trusting.** I reconcile counts at every step and audit
  cleaned data before using it.
- **Flag, don't guess.** If only the client can explain something, I report
  it instead of making up a value.
- **Write it down.** Every change is logged, and every README has a
  limitations section.
